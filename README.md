Назва проєкту
Веб-додаток для онлайн-бронювання комп’ютерів у комп’ютерному клубі NOOB.

Що реалізовано
У проєкті реалізовано веб-сайт комп’ютерного клубу, який дозволяє користувачам переглядати доступні комп’ютери та приставки PS5, обирати потрібне ігрове місце та створювати бронювання онлайн. Користувач вводить своє ім’я, номер телефону, обирає дату, годину та хвилини бронювання, після чого система перевіряє правильність введених даних і зберігає запис у базі даних.
Також реалізовано адміністративну панель, у якій адміністратор може переглядати створені бронювання, бачити дані клієнтів, дату та час запису, а також змінювати статус комп’ютерів і приставок на «вільний» або «зайнятий». На сайті додатково розміщено прайс і графік роботи комп’ютерного клубу.

Які технології використані
Для створення проєкту були використані такі технології:
HTML — для створення структури веб-сторінок;
CSS — для оформлення інтерфейсу, адаптивності та візуальних ефектів;
JavaScript — для реалізації логіки бронювання, перевірки даних, відкриття модального вікна та взаємодії з базою даних;
Firebase Firestore — для зберігання бронювань і статусів комп’ютерів у хмарній базі даних;
Firebase SDK — для підключення веб-додатку до бази даних;
Google Chrome або інший сучасний браузер — для перегляду та тестування сайту.
